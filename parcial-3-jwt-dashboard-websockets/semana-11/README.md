# Semana 11 (2-6 nov) (*) — Programación Web

**Tipo:** Individual

**Tema oficial:** inicio de Unidad 3 — Ciberseguridad: introducción, principios de la ciberseguridad, personas y roles.

**Objetivo:** conocer los principios básicos de ciberseguridad (confidencialidad, integridad, disponibilidad) y los roles involucrados, antes de tocar código de autenticación.

**Prerrequisitos:** Parcial 2 (login usuario/contraseña sin JWT).

**Actividad:** ejercicio aislado — análisis de un caso de brecha de seguridad real (ej. contraseñas en texto plano, sesión sin expiración) y clasificación de qué principio se violó.

**Entregable:** reporte de análisis de caso + clasificación por principio (confidencialidad/integridad/disponibilidad).
