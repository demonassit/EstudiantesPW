# cecyt9-web

Prácticas de Programación Web, sobre el proyecto real de gestión de cursos/talleres del CECyT9. Este repo **no contiene código de la aplicación** — el código vive en el repo de tu equipo `cecyt9-proyecto`. Aquí solo hay instrucciones semana por semana.

## Estructura

```
docs/guia-git-equipo.md               → Git para trabajo en equipo + Práctica 0
parcial-1-landing-page/               → semanas 1-5 · corte: LANDING PAGE COMPLETA
parcial-2-bd-supabase-auth/           → semanas 6-10 · corte: CRUD usuarios + BD local/Supabase + login sin JWT
parcial-3-jwt-dashboard-websockets/   → semanas 11-15 · corte: JWT + captcha + dashboard, app completa
```

Cada carpeta `semana-XX/` trae un `README.md` con: tema oficial, objetivo, prerrequisitos, actividad y entregable. La rúbrica de evaluación la tiene tu docente por separado.

## Cómo entregar

Cuando una semana pida código (HTML/CSS, CRUD, login, JWT, dashboard), impleméntalo en `frontend/` o `backend/` del repo `cecyt9-proyecto` de tu equipo y entrega el **link al commit o Pull Request correspondiente**, no un archivo suelto.

## Antes de la Semana 1

Haz la **Práctica 0** de `docs/guia-git-equipo.md` con tu equipo — es la práctica de Git donde provocan y resuelven un conflicto de merge real, antes de que les pase en una entrega que sí cuenta.
